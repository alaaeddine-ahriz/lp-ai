# Photos

Déposer ici des photos (JPG, PNG ou WebP). Elles sont converties en AVIF à plusieurs tailles au build.
Un fichier absent ne casse rien : la section garde son visuel par défaut.

| Fichier | Où | Format conseillé |
| --- | --- | --- |
| `hero.jpg` | Fond du hero (un voile sombre est appliqué) | Paysage, 2400 px de large minimum |
| `team.jpg` | Section « Qui est derrière » | 4:3, 1200 px de large minimum |
| `pole-direction.jpg` | La carte, pôle Direction | Portrait ou carré, 800 px minimum |
| `pole-marketing.jpg` | La carte, pôle Marketing | idem |
| `pole-prospection.jpg` | La carte, pôle Prospection | idem |
| `pole-vente.jpg` | La carte, pôle Vente | idem |
| `pole-production.jpg` | La carte, pôle Production | idem |
| `pole-rh.jpg` | La carte, pôle RH | idem |
| `pole-finance.jpg` | La carte, pôle Finance | idem |
| `pole-juridique.jpg` | La carte, pôle Juridique | idem |

Les photos des pôles reçoivent un dégradé sombre en bas pour garder le titre lisible.
